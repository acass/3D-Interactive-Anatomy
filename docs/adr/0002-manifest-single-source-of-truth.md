# Feature Manifest is the single source of truth; the assistant is grounded to it

Every explainable feature is defined once in a hand-authored Feature Manifest (`id`, `label`, surface `position` + `normal`, and authored `explanation`). That one file renders the callouts, supplies the camera targets, and is handed to the Live API as grounding so the assistant narrates authored text rather than inventing facts about the model. The deliberate constraint — the assistant does not generate specifications about the model beyond the manifest — is not visible from the code alone, so it is recorded here. It also defines the placeholder-to-real swap contract: replacing the GLB and rewriting the manifest changes the entire subject with no code changes. Off-manifest questions get a brief conversational answer and trigger no camera move.
